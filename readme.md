# Dual-Channel Fraud Risk Control

Research project exploring dual-channel expected-loss
control using investigator reviews and delayed
chargeback feedback.

## Project Structure

- `data/`: Raw and processed datasets
- `src/`: Implementation
- `tests/`: Automated tests
- `notebooks/`: Exploratory analysis
- `results/`: Experimental results

## Datasets

1. ULB Credit Card Fraud Detection
2. Sparkov Fraud Detection

Raw datasets are not committed to this repository.
